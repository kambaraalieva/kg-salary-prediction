# Прогноз зарплаты по вакансиям Кыргызстана

ML-модель, которая по описанию вакансии предсказывает месячную зарплату в сомах и интервал,
в который зарплата попадает с вероятностью ~80%. Цель: дать ориентир по рынку для 52% вакансий,
где работодатель скрыл зарплату.

Данные и их анализ: репозиторий [kg-job-market-analysis](https://github.com/kambaraalieva/kg-job-market-analysis).

## Результаты

| Модель | MAE, кросс-валидация | MAE, тест | R² (log), тест |
|---|---|---|---|
| Медиана профессии (базовая линия) | 17 718 ± 754 | 17 793 | 0,21 |
| Ridge | 17 344 ± 811 | 17 512 | 0,26 |
| LightGBM | 17 247 ± 764 | 17 544 | 0,26 |
| Random Forest | 17 122 ± 718 | 18 037 | 0,23 |
| CatBoost | 16 888 ± 739 | 17 112 | 0,29 |
| CatBoost + текст | не считалась | ≈ 16 550 | 0,33 |
| Ridge + TF-IDF | 16 246 ± 695 | 16 249 | 0,36 |
| **Финальная модель** (новые текстовые признаки + Optuna) | **15 610** | **15 763** | **0,38** |

- **Ошибка на 11% ниже базовой линии.** Половина прогнозов ошибается меньше чем на ~9 500 сом.
- **Интервал прогноза** (конформный, 10–90 перцентили ошибок): реальная зарплата попала
  в него в 79% случаев на тесте; типичная ширина от 0,6 до 1,75 прогноза.
- **Текст объявления важнее сложности модели:** бустинг на структурированных полях почти не лучше
  медианы профессии, а текст снижает ошибку на 9%.
- **Проверено 12 моделей** (линейные, деревья, бустинг, kNN, смеси, нейросетевые эмбеддинги):
  ни одна не лучше финальной Ridge больше чем на разброс между фолдами. Предел задаёт шум в данных:
  объявления с одинаковым названием различаются по зарплате в среднем на ~12 000 сом.
- **По сегментам:** массовые вакансии 25–40 тыс.: MAE ~7 900 сом; медианная ошибка по рынку ~9 500.
- **Модель надёжна для типичных зарплат** (25–60 тыс.: более половины прогнозов в пределах 20%)
  и тянет к середине крайние значения (низкие завышает, очень высокие занижает).

## Модель для текущего рынка (2024–2026)

Ноутбук `07_time_split`: **22 563 уникальные вакансии с зарплатой** (2024: 9 805, 2025: 6 627, 2026: 6 131;
повторные публикации той же вакансии за 30 дней удалены). Обучение на январе 2024 – июне 2026,
**тест на 1 784 вакансиях июля–октября 2026**, которых модель не видела (вакансии того же работодателя
с тем же заголовком из теста удалены).

| Модель | MAE на 2026, сом | Медианная ошибка | Смещение | R² (log) |
|---|---|---|---|---|
| Медиана рынка за последние 6 месяцев | 34 365 | 20 000 | −8% | −0,05 |
| Медиана профессии за последние 6 месяцев | 30 886 | 20 000 | −4% | 0,14 |
| Модель 2024 года без переобучения | 39 072 | 24 666 | **−36%** | −0,59 |
| Обучение на 2024–2026 | 27 780 | 17 520 | −8% | 0,31 |
| + месяц публикации | 27 616 | 17 068 | −0,3% | 0,34 |
| + работодатель | 26 634 | 16 532 | +1% | 0,37 |
| то же, только 2025–2026 | 26 673 | 16 755 | +2% | 0,35 |
| **+ уровень (junior…lead), сфера × опыт (финальная)** | **26 693** | **16 543** | **+1%** | **0,37** |

- Модель 2024 года занижает сегодняшние зарплаты на треть: зарплаты в вакансиях выросли примерно на 31%.
- Новая модель без перекоса; медианная ошибка около 25% от типичной зарплаты теста (65 000 сом).
  Это предел данных: одинаковые заголовки у разных работодателей за один квартал различаются на 25%.
- Финальная модель выбрана за реалистичное влияние опыта при той же точности: Frontend без уровня в заголовке,
  опыт 0 / 1 / 3 / 6 лет: прогноз 50 / 79 / 116 / 136 тыс., реальные медианы 56 / 80 / 120 / 164 тыс.
  Уровень берётся из заголовка (Senior, Junior…), а если его нет, из требуемого опыта.
- Диапазоны проверены на будущем: 50% диапазон накрыл 50% вакансий, 80% диапазон накрыл 80%.
- **Улучшение (ноутбук 08):** формат вакансии из поля «Тип», поле «Дополнительно», больший вес свежих
  вакансий и смесь Ridge + LightGBM: **MAE 25 191 сом** (−5,6%), медианная ошибка **15 268** (−8%),
  80% диапазон накрыл 80% вакансий. Настройки выбраны на валидации (апрель–июнь 2026), тест открыт один раз.
- Живой прогноз для любой вакансии:
  ```bash
  python src/predict.py "Менеджер по продажам" --exp 1
  python src/predict.py "Официант" --exp 0 --source telegram_kgworkzone
  ```

## Постановка

- **Задача:** регрессия, цель `log(зарплаты)` (распределение зарплат скошено).
- **Данные:** 5 820 вакансий с зарплатой (hh.kg и lalafo.kg, февраль–март 2024);
  6 516 вакансий со скрытой зарплатой используются только для предсказания.
- **Признаки:** сфера, профессия, город, источник, опыт, образование, требование к полу, график,
  удалёнка, проценты/бонусы, язык, число навыков, длина текста; текст названия, требований и обязанностей.
- **Защита от утечки:**
  - не используются колонки, которые есть только при указанной зарплате (валюта, формат, период);
  - из текста удалены числа и названия валют (иначе модель «читает» зарплату из текста объявления).
- **Шум в разметке:** убраны 20 объявлений lalafo с зарплатой в 5+ раз выше или ниже медианы профессии.
- **Разбиение:** 80/20 с группировкой почти одинаковых объявлений; 5-кратная групповая
  кросс-валидация на обучающей части.
- **Метрики:** MAE в сомах (основная), медианная ошибка, MAPE, доля ошибок < 20%, R² на log.

## Как запустить

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt          # на macOS для LightGBM также: brew install libomp
cd notebooks
for nb in 01_baseline 02_model_comparison 03_tuning 04_error_analysis 05_more_models 07_time_split 08_improvements; do
  jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=2400 $nb.ipynb
done
```

## Ограничения

- Модели 01–06 обучены на начале 2024 года; для текущих зарплат использовать `model_2026` (ноутбук 07).
- Данные 2025–2026 почти целиком из двух Telegram-каналов: офисные, IT и продажи (codifynews) и сфера услуг Бишкека (kgworkzone).
- Это ориентир по рынку, а не точная зарплата: объявления с одинаковыми признаками различаются
  по зарплате в среднем на 25%.
- Если работодатели скрывают зарплату именно потому, что она выше рынка, модель этого не увидит.
