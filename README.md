# Прогноз зарплаты по вакансиям Кыргызстана

ML-модель, которая по описанию вакансии предсказывает месячную зарплату в сомах.
Цель: оценить зарплату для 52% вакансий, где работодатель её скрыл.

Данные и их анализ: репозиторий [kg-job-market-analysis](https://github.com/kambaraalieva/kg-job-market-analysis).

## Текущие результаты (чекпоинт 30.10)

| Модель | MAE, кросс-валидация | MAE, тест | R² (log), тест |
|---|---|---|---|
| Медиана профессии (базовая линия) | 18 912 ± 746 | 16 885 | 0,21 |
| Ridge | 18 531 ± 503 | 16 725 | 0,25 |
| LightGBM | 18 497 ± 487 | 16 657 | 0,27 |
| Random Forest | 18 301 ± 300 | 16 674 | 0,25 |
| CatBoost | 18 120 ± 266 | 16 443 | 0,27 |
| CatBoost + текст | не считалась | ≈ 15 700 | 0,33 |
| **Ridge + TF-IDF** | **17 209 ± 594** | **15 334** | **0,36** |

**Главный вывод:** текст объявления даёт больше, чем сложность модели. Модели на структурированных
признаках почти не лучше медианы профессии, а добавление текста снижает ошибку на 9%.

## Постановка

- **Задача:** регрессия, цель `log(зарплаты)` (распределение зарплат скошено).
- **Данные:** 5 840 вакансий с зарплатой (hh.kg и lalafo.kg, февраль–март 2024);
  6 516 вакансий со скрытой зарплатой используются только для предсказания.
- **Признаки:** сфера, профессия, город, источник, опыт, образование, требование к полу, график,
  удалёнка, проценты/бонусы, язык, число навыков, длина текста; текст названия и требований.
- **Защита от утечки:** не используются колонки, которые есть только при указанной зарплате.
- **Разбиение:** 80/20 с группировкой почти одинаковых объявлений; 5-кратная групповая
  кросс-валидация на обучающей части.
- **Метрики:** MAE в сомах (основная), медианная ошибка, MAPE, доля ошибок < 20%, R² на log.

## Как запустить

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cd notebooks
jupyter nbconvert --to notebook --execute --inplace 01_baseline.ipynb
jupyter nbconvert --to notebook --execute --inplace 02_model_comparison.ipynb
```
